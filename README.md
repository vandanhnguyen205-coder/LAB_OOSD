# LAB_OOSD

## Nguyễn Văn Danh · CNPM1

Chào mừng bạn đến với repository tổng hợp các bài thực hành môn **Phát triển phần mềm hướng đối tượng (OOSD)**. Repository lưu trữ bài tập, tài liệu và các ứng dụng được thực hiện trong quá trình học tập, từ bài tập Java cơ bản đến các hệ thống quản lý xây dựng bằng C# và SQL Server.

## Danh sách bài lab

| Bài lab | Nội dung | Công nghệ chính |
|---|---|---|
| [LAB1](./LAB1/) | Đặc tả Use Case và bài tập Java về các hình học cơ bản | Java |
| [LAB2](./LAB2/) | Ứng dụng quản lý thư viện | C# WinForms, SQL Server |
| [LAB3](./LAB3/) | Ứng dụng quản lý khách sạn | C# WinForms, SQL Server |
| [LAB4](./LAB4/) | Ứng dụng eShopping | C# WinForms, SQL Server |
| [LAB5](./LAB5/) | Hệ thống quản lý công ty du lịch văn hóa Việt | C# WinForms, SQL Server, UML |

## Tổng quan

Các bài lab tập trung vào việc vận dụng kiến thức phân tích, thiết kế và phát triển phần mềm hướng đối tượng. Nội dung được sắp xếp theo từng thư mục để tiện theo dõi mã nguồn, tài liệu và cơ sở dữ liệu của mỗi bài.
